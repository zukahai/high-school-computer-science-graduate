Mục 5.3 – CSS Cơ Bản ​

🔹 1. GIỚI THIỆU SIÊU CƠ BẢN ​

Tại sao cần CSS?

Hãy tưởng tượng bạn đã xây xong khung nhà (HTML). Nhưng tường trắng toát, không có màu sắc, đèn đóm, rèm cửa – trông rất buồn tẻ. CSS chính là người trang trí nội thất – tô màu tường, chọn font chữ, kẻ đường viền, sắp xếp bố cục.

Không có CSS, mọi trang web đều trông như một tờ văn bản thô trên nền trắng. CSS biến trang web từ "bản nháp" thành "tác phẩm đẹp".

CSS là gì?

  • CSS = Cascading Style Sheets (Bảng định kiểu theo tầng)
  • CSS mô tả cách hiển thị các phần tử HTML (màu sắc, phông chữ, kích thước, căn lề...)
  • CSS tách phần nội dung (HTML) khỏi phần trình bày (CSS)

Ví dụ thực tế: Cùng một bài viết, nhưng trang VnExpress và Facebook hiển thị rất khác nhau – vì họ dùng CSS khác nhau.

🔹 2. LÝ THUYẾT CHI TIẾT ​

Cú pháp CSS cơ bản ​

css
selector {
  thuộc-tính: giá-trị;
}
  • Selector = Chọn phần tử HTML nào cần định dạng (ví dụ: p, h1, .tên-class, #tên-id)
  • Thuộc tính = Điều bạn muốn thay đổi (ví dụ: color, font-size, border)
  • Giá trị = Giá trị bạn muốn đặt (ví dụ: red, 16px, 1px solid black)

3 cách áp dụng CSS vào HTML ​

CáchVí dụKhi nào dùng
Inline (trong thẻ)<p style="color:red;">Nhanh, một lần, không khuyến khích
Internal (trong <style>)Đặt <style> trong <head>Trang đơn lẻ
External (file riêng)<link rel="stylesheet" href="style.css">Dự án lớn, nhiều trang

Thuộc tính font-family ​

css
p {
  font-family: Arial, Helvetica, sans-serif;
}
  • Liệt kê nhiều font cách nhau bằng dấu phẩy → trình duyệt dùng font đầu tiên có sẵn
  • Font cuối cùng (sans-serif) là font dự phòng chung, luôn có sẵn

Thuộc tính border ​

Cú pháp: border: [độ-dày] [kiểu] [màu]

css
div {
  border: 2px solid red;
}
  • 2px → đường viền dày 2 pixel
  • solid → kiểu đường liền (các kiểu khác: dashed, dotted, double)
  • red → màu đỏ

🔹 3. GIẢI THÍCH BẢN CHẤT ​

CSS là gì thực chất?

Hãy so sánh với quần áo:

  • HTML = cơ thể người (cấu trúc)
  • CSS = bộ quần áo (trang trí)

Cùng một người (HTML), mặc đồng phục học sinh trông khác, mặc đồ thể thao trông khác – nhưng người đó không thay đổi. Đó là cách CSS hoạt động.

Tại sao gọi là "Cascading" (theo tầng)?

Cascade = nước chảy theo tầng. Khi có nhiều quy tắc CSS cùng áp dụng cho một phần tử, CSS có quy tắc ưu tiên rõ ràng:

  1. Inline style (mạnh nhất)
  2. Internal style (<style> trong <head>)
  3. External style (file .css)
  4. Trình duyệt mặc định (yếu nhất)

🔹 4. LUỒNG HOẠT ĐỘNG STEP-BY-STEP ​

Cách trình duyệt áp dụng CSS:

  1. Tải file HTML → đọc cấu trúc trang
  2. Tìm CSS → đọc từ file .css liên kết, thẻ <style>, và style inline
  3. Xây dựng cây DOM → lập sơ đồ cấu trúc HTML
  4. Áp dụng CSS vào từng phần tử → tính toán màu sắc, font, kích thước
  5. Giải quyết xung đột → khi nhiều rule cùng chọn 1 phần tử, dùng quy tắc độ ưu tiên
  6. Tính toán layout → xác định vị trí, kích thước từng phần tử
  7. Vẽ ra màn hình → hiển thị trang web hoàn chỉnh với giao diện đẹp

🔹 5. VÍ DỤ MINH HỌA ​

Ví dụ 1 – Cơ bản: CSS Inline và Internal ​

html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>CSS Cơ Bản</title>
    <style>
      h1 {
        color: blue;
        font-family: Arial, sans-serif;
      }
      p {
        font-size: 16px;
        color: #333333;
      }
    </style>
  </head>
  <body>
    <h1>Tiêu đề màu xanh</h1>
    <p>Đoạn văn màu xám đậm, cỡ 16px.</p>
    <p style="color: red;">Đoạn này dùng inline CSS – màu đỏ.</p>
  </body>
</html>

Giải thích từng dòng:

  • <style> trong <head> → Viết CSS trực tiếp trong file HTML (Internal CSS)
  • h1 { color: blue; } → Chọn tất cả thẻ <h1>, đặt màu chữ = xanh
  • font-family: Arial, sans-serif; → Font chữ Arial; nếu không có thì dùng sans-serif
  • p { font-size: 16px; color: #333333; } → Chọn tất cả <p>, cỡ 16px, màu xám
  • style="color: red;" → CSS inline ghi đè lên CSS trong <style> → chữ đỏ

Ví dụ 2 – Thực tế: Trang web có CSS trang trí ​

html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>Trang web lớp học</title>
    <style>
      body {
        font-family: Arial, sans-serif;
        background-color: #f0f4f8;
        margin: 20px;
      }

      h1 {
        color: #1a73e8;
        text-align: center;
        font-size: 28px;
      }

      .hop-thong-tin {
        border: 2px solid #1a73e8;
        padding: 15px;
        background-color: white;
        width: 400px;
      }

      ul li {
        font-size: 14px;
        color: #555;
      }
    </style>
  </head>
  <body>
    <h1>Lớp 10A1 – Trường THPT Nguyễn Huệ</h1>

    <div class="hop-thong-tin">
      <h2>Thông tin lớp</h2>
      <ul>
        <li>Sĩ số: 35 học sinh</li>
        <li>GVCN: Thầy Nguyễn Văn Minh</li>
        <li>Phòng: B201</li>
      </ul>
    </div>
  </body>
</html>

Giải thích:

  • body { font-family: ... } → Đặt font cho toàn bộ trang
  • background-color: #f0f4f8 → Màu nền xanh nhạt nhẹ mắt
  • .hop-thong-tin → Selector dạng class (bắt đầu bằng .), chọn thẻ có class="hop-thong-tin"
  • border: 2px solid #1a73e8 → Viền xanh Google 2px, đường liền
  • padding: 15px → Khoảng cách từ viền vào đến nội dung bên trong = 15px
  • ul li → Chọn tất cả <li> nằm trong <ul> (selector lồng nhau)

Ví dụ 3 – Nâng cao: File CSS tách riêng ​

File: index.html

html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>Blog học sinh</title>
    <link rel="stylesheet" href="style.css">
  </head>
  <body>
    <div id="tieu-de-chinh">
      <h1>Blog Tin Học</h1>
    </div>
    <div class="bai-viet">
      <h2>Bài 1: HTML là gì?</h2>
      <p>HTML là ngôn ngữ đánh dấu siêu văn bản...</p>
    </div>
    <div class="bai-viet">
      <h2>Bài 2: CSS là gì?</h2>
      <p>CSS giúp trang web trở nên đẹp hơn...</p>
    </div>
  </body>
</html>

File: style.css

css
/* Định dạng chung */
body {
  font-family: 'Times New Roman', Times, serif;
  margin: 0;
  padding: 0;
  background-color: #fafafa;
}

/* Tiêu đề chính */
#tieu-de-chinh {
  background-color: #2c3e50;
  color: white;
  text-align: center;
  padding: 30px;
}

/* Mỗi bài viết */
.bai-viet {
  border: 1px solid #ddd;
  border-radius: 8px;
  padding: 20px;
  margin: 15px auto;
  width: 600px;
  background-color: white;
}

.bai-viet h2 {
  color: #2980b9;
  font-size: 20px;
}

Giải thích nâng cao:

  • <link rel="stylesheet" href="style.css"> → Liên kết file CSS bên ngoài vào HTML
  • #tieu-de-chinh → Selector dạng ID (bắt đầu bằng #), chọn thẻ có id="tieu-de-chinh" – chỉ dùng 1 lần/trang
  • border-radius: 8px → Bo tròn góc viền
  • margin: 15px auto → 15px trên/dưới, auto tự căn giữa theo chiều ngang
  • .bai-viet h2 → Chỉ chọn <h2> bên trong .bai-viet, không ảnh hưởng <h2> khác

🔹 7. GHI NHỚ NHANH (ĐI THI) ​

  • ✅ CSS = Cascading Style Sheets – định dạng giao diện cho HTML
  • ✅ Cú pháp: selector { thuộc-tính: giá-trị; }
  • ✅ 3 cách dùng: Inline (style="") > Internal (<style>) > External (file .css)
  • ✅ font-family = phông chữ; liệt kê nhiều font phòng trường hợp máy không có
  • ✅ border: 2px solid red = viền 2px, đường liền, màu đỏ
  • ✅ .class → selector class (bắt đầu dấu chấm); #id → selector ID (bắt đầu dấu thăng)
  • ✅ padding = khoảng cách bên trong viền; margin = khoảng cách bên ngoài viền
  • ✅ External CSS dùng <link rel="stylesheet" href="file.css"> trong <head>

🔹 8. BÀI TẬP TỰ LUYỆN ​

Câu 1 (Dễ): CSS là viết tắt của cụm từ nào? ​

A. Computer Style Sheets
B. Cascading Style Sheets
C. Creative Style System
D. Color and Style Sheets

Đáp án: B – Cascading Style Sheets (Bảng định kiểu theo tầng).

Câu 2 (Dễ): Đoạn CSS sau làm gì? ​

css
h1 {
  color: green;
  font-size: 24px;
}

Đáp án: Chọn tất cả thẻ <h1> trong trang, đặt màu chữ thành xanh lá và cỡ chữ thành 24 pixel.

Câu 3 (Trung bình): Sự khác nhau giữa .lop-hoc và #lop-hoc trong CSS là gì? ​

Đáp án:

  • .lop-hoc → Selector class, áp dụng cho nhiều phần tử có class="lop-hoc"
  • #lop-hoc → Selector ID, chỉ áp dụng cho một phần tử duy nhất có id="lop-hoc" trên trang

Câu 4 (Trung bình): Viết CSS để tạo đoạn văn có: font chữ Arial, cỡ 18px, màu chữ xanh navy, viền đen đứt nét 1px. ​

Đáp án:

css
p {
  font-family: Arial, sans-serif;
  font-size: 18px;
  color: navy;
  border: 1px dashed black;
}

Câu 5 (Vận dụng): Tạo file HTML và CSS riêng: trang có tiêu đề <h1> căn giữa màu tím, nền trang màu vàng nhạt, và một đoạn văn <p> có viền đỏ. ​

Đáp án mẫu:

index.html:

html
<!DOCTYPE html>

  <body>
    <h1>Trang web của tôi</h1>
    <p>Đây là đoạn văn có viền đỏ.</p>
  </body>
</html>

style.css:

  background-color: #fffde7;
}

  color: purple;
