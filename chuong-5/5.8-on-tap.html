🔹 1. TỔNG HỢP TOÀN BỘ THẺ HTML DÙNG TRONG THI TỐT NGHIỆP ​

Nhóm 1: Cấu trúc trang ​

ThẻÝ nghĩa
<!DOCTYPE html>Khai báo loại tài liệu HTML5
<html lang="vi">Thẻ gốc, khai báo ngôn ngữ
<head>Phần đầu (thông tin ẩn)
<body>Phần thân (nội dung hiển thị)
<meta charset="UTF-8">Hỗ trợ tiếng Việt có dấu
<title>Tiêu đề trên tab trình duyệt
<link rel="stylesheet" href="style.css">Liên kết file CSS ngoài

Nhóm 2: Tiêu đề và văn bản ​

ThẻÝ nghĩa
<h1> – <h6>Tiêu đề (h1 lớn nhất → h6 nhỏ nhất)
<p>Đoạn văn bản

<em>In nghiêng (nhấn mạnh)
<br>Xuống dòng (tự đóng)
<hr>Đường kẻ ngang (tự đóng)
<pre>Giữ nguyên định dạng văn bản
<code>Đoạn mã lập trình

Nhóm 3: Danh sách ​

ThẻÝ nghĩa

<ol>Danh sách có thứ tự (số 1, 2, 3...)

🔹 4. BỘ ĐỀ ÔN TẬP TỔNG HỢP ​

Phần A – Câu hỏi trắc nghiệm lý thuyết ​

Câu 1: Thẻ nào không tự đóng (cần thẻ đóng)?

A. <img>
B. <input>
C. <br>
D. <textarea>

Đáp án: D – <textarea> cần thẻ đóng </textarea>. <img>, <input>, <br> đều là thẻ tự đóng.

Câu 2: Để liên kết mở trong tab mới, thuộc tính và giá trị nào cần thêm vào thẻ <a>?

A. method="_blank"
B. target="_blank"
C. href="_blank"
D. open="new"

Đáp án: B – target="_blank" chỉ định liên kết mở trong tab mới.

Câu 3: Trong CSS, padding: 10px 20px có nghĩa là:

A. Trên/dưới: 10px, Trái/phải: 20px
B. Trên: 10px, Phải: 20px, Dưới: 10px, Trái: 20px
C. Trái/phải: 10px, Trên/dưới: 20px
D. Padding 10px trên tất cả 4 cạnh, sau đó 20px

Đáp án: A – Khi padding có 2 giá trị: giá trị đầu là trên/dưới (10px), giá trị sau là trái/phải (20px).

Câu 4: Thẻ nào dùng để tạo danh sách có đánh số thứ tự?

A. <ul>
B. <li>
C. <ol>
D. <dl>

Đáp án: C – <ol> (Ordered List) tạo danh sách đánh số 1, 2, 3...

Câu 5: Trong bảng HTML, thẻ nào tạo ô tiêu đề với chữ tự động in đậm và căn giữa?

A. <td>
B. <tr>
C. <caption>
D. <th>

Đáp án: D – <th> (Table Header) tự động in đậm và căn giữa.

Câu 6: Selector CSS nào chọn tất cả phần tử có class="noi-bat"?

A. #noi-bat
B. .noi-bat
C. *noi-bat
D. @noi-bat

Đáp án: B – Dấu chấm . trước tên là selector class. # là selector ID.

Câu 7: Thuộc tính nào của <form> xác định địa chỉ nhận dữ liệu khi submit?

A. method
B. name
C. action
D. target

Đáp án: C – action xác định URL mà form gửi dữ liệu đến khi người dùng submit.

Câu 8: colspan="3" trong <td> có nghĩa là:

A. Ô đó nằm ở cột thứ 3
B. Ô đó gộp 3 hàng lại
C. Ô đó gộp 3 cột lại
D. Cột đó có 3 ô

Đáp án: C – colspan (column span) gộp nhiều cột theo chiều ngang.

Phần B – Câu hỏi phân tích mã ​

Câu 9: Đoạn mã HTML sau tạo ra gì? Có lỗi không?

html
<form method="post">
  <input type="text" placeholder="Tên bạn">
  <input type="submit" value="Gửi">
</form>

Đáp án: Tạo form với ô nhập tên và nút gửi. Có một vấn đề: <input type="text"> thiếu thuộc tính name → dữ liệu sẽ không được gửi đi khi submit. Sửa lại: Thêm name="ten" vào input.

Câu 10: Đoạn CSS sau có tác dụng gì?

css
.the-bai {
  width: 600px;
  margin: 20px auto;
  padding: 15px;
  border: 1px solid #ccc;
  border-radius: 10px;
}

Đáp án:

  • width: 600px → phần tử rộng 600px
  • margin: 20px auto → 20px cách trên/dưới, tự động căn giữa trang theo chiều ngang
  • padding: 15px → khoảng cách 15px từ viền vào nội dung bên trong
  • border: 1px solid #ccc → viền màu xám nhạt, đường liền, dày 1px
  • border-radius: 10px → bo tròn bốn góc 10px → Kết quả: hộp nội dung đẹp, căn giữa trang, có viền bo tròn.

🔹 5. BẢNG SO SÁNH NHANH – CÁC CẶP DỄ NHẦM ​

CặpĐiểm phân biệt chính
<ul> vs <ol>ul = dấu chấm (không thứ tự); ol = đánh số (có thứ tự)
<th> vs <td>th = tiêu đề (đậm, giữa); td = dữ liệu thường
colspan vs rowspancolspan = gộp cột ngang; rowspan = gộp hàng dọc
<input> vs <textarea>input = 1 dòng, tự đóng; textarea = nhiều dòng, có thẻ đóng
radio vs checkboxradio = chọn 1; checkbox = chọn nhiều
<div> vs <span>div = block (xuống dòng); span = inline (trong dòng)
margin vs paddingmargin = ngoài viền; padding = trong viền
href vs srchref = đích liên kết <a>; src = nguồn ảnh <img>
<strong> vs <b>strong = đậm + có nghĩa; b = chỉ đậm trình bày
GET vs POSTGET = hiện trên URL; POST = ẩn trong request
display:none vs visibility:hiddennone = ẩn không chiếm chỗ; hidden = ẩn vẫn chiếm chỗ
position: relative vs absoluterelative = giữ chỗ; absolute = lấy khỏi luồng

🔹 6. GHI NHỚ NHANH TỔNG HỢP (ĐI THI) ​

HTML:

  • ✅ Cấu trúc bắt buộc: <!DOCTYPE html> → <html> → <head> + <body>
  • ✅ <meta charset="UTF-8"> → trong <head>, hỗ trợ tiếng Việt
  • ✅ <title> → hiển thị trên tab trình duyệt, không trong trang
  • ✅ <img>, <input>, <br>, <hr> → thẻ tự đóng
  • ✅ Bảng: table > tr > th/td; colspan = ngang; rowspan = dọc
  • ✅ Form: cần name trên mọi input để gửi dữ liệu
  • ✅ <a href="url"> / target="_blank" / href="mailto:" / href="#id"

CSS:

  • ✅ Selector: thẻ { } / .class { } / #id { } / cha con { }
  • ✅ Box Model: Content → Padding → Border → Margin (trong → ngoài)
  • ✅ margin: 0 auto + width → căn giữa block
  • ✅ padding = trong viền (có nền); margin = ngoài viền (trong suốt)
  • ✅ display: none → ẩn; block → chiếm hàng; inline-block → trong dòng có width/height
  • ✅ position: fixed → cố định màn hình; absolute → theo cha có position: relative
