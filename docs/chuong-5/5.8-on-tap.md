## 🔹 1. TỔNG HỢP TOÀN BỘ THẺ HTML DÙNG TRONG THI TỐT NGHIỆP

### Nhóm 1: Cấu trúc trang

| Thẻ | Ý nghĩa |
|-----|---------|
| `<!DOCTYPE html>` | Khai báo loại tài liệu HTML5 |
| `<html lang="vi">` | Thẻ gốc, khai báo ngôn ngữ |
| `<head>` | Phần đầu (thông tin ẩn) |
| `<body>` | Phần thân (nội dung hiển thị) |
| `<meta charset="UTF-8">` | Hỗ trợ tiếng Việt có dấu |
| `<title>` | Tiêu đề trên tab trình duyệt |
| `<link rel="stylesheet" href="style.css">` | Liên kết file CSS ngoài |

### Nhóm 2: Tiêu đề và văn bản

| Thẻ | Ý nghĩa |
|-----|---------|
| `<h1>` – `<h6>` | Tiêu đề (h1 lớn nhất → h6 nhỏ nhất) |
| `<p>` | Đoạn văn bản |
| `<strong>` | In **đậm** (quan trọng) |
| `<em>` | In *nghiêng* (nhấn mạnh) |
| `<br>` | Xuống dòng (tự đóng) |
| `<hr>` | Đường kẻ ngang (tự đóng) |
| `<pre>` | Giữ nguyên định dạng văn bản |
| `<code>` | Đoạn mã lập trình |

### Nhóm 3: Danh sách

| Thẻ | Ý nghĩa |
|-----|---------|
| `<ul>` | Danh sách không thứ tự (dấu chấm •) |
| `<ol>` | Danh sách có thứ tự (số 1, 2, 3...) |
| `<li>` | Mỗi mục trong danh sách |

### Nhóm 4: Liên kết và hình ảnh

| Thẻ / Thuộc tính | Ý nghĩa |
|-----------------|---------|
| `<a href="url">` | Tạo liên kết |
| `target="_blank"` | Mở trong tab mới |
| `href="mailto:email"` | Liên kết gửi email |
| `href="#id"` | Liên kết neo trong trang |
| `<img src="url" alt="mô tả">` | Chèn hình ảnh (tự đóng) |
| `width` / `height` | Kích thước ảnh |

### Nhóm 5: Bảng HTML

| Thẻ | Ý nghĩa |
|-----|---------|
| `<table>` | Bao ngoài toàn bộ bảng |
| `<tr>` | Hàng ngang (Table Row) |
| `<th>` | Ô tiêu đề (đậm, căn giữa) |
| `<td>` | Ô dữ liệu (bình thường) |
| `<thead>` | Nhóm hàng tiêu đề (tùy chọn) |
| `<tbody>` | Nhóm hàng dữ liệu (tùy chọn) |
| `colspan="n"` | Gộp n cột ngang |
| `rowspan="n"` | Gộp n hàng dọc |

### Nhóm 6: Form HTML

| Thẻ / Thuộc tính | Ý nghĩa |
|-----------------|---------|
| `<form action="url" method="post/get">` | Khung form |
| `<input type="text">` | Ô nhập chữ một dòng |
| `<input type="password">` | Ô nhập mật khẩu (ẩn ký tự) |
| `<input type="email">` | Ô nhập email (kiểm tra @) |
| `<input type="number">` | Ô nhập số |
| `<input type="radio">` | Nút tròn chọn một |
| `<input type="checkbox">` | Ô vuông chọn nhiều |
| `<input type="submit">` | Nút gửi form |
| `<input type="date">` | Bộ chọn ngày |
| `<select>` + `<option>` | Danh sách thả xuống |
| `<textarea rows cols>` | Ô nhập nhiều dòng |
| `<button type="submit/reset/button">` | Nút bấm |
| `<label for="id">` | Nhãn gắn với ô nhập |
| `name` | Tên trường (bắt buộc để gửi dữ liệu) |
| `placeholder` | Gợi ý mờ trong ô nhập |

### Nhóm 7: Semantic HTML & Nhóm phần tử

| Thẻ | Ý nghĩa |
|-----|---------|
| `<header>` | Phần đầu trang |
| `<nav>` | Khu vực điều hướng/menu |
| `<main>` | Nội dung chính |
| `<section>` | Phần/mục nội dung |
| `<article>` | Bài viết độc lập |
| `<aside>` | Nội dung phụ (sidebar) |
| `<footer>` | Chân trang |
| `<div>` | Nhóm block (không semantic) |
| `<span>` | Nhóm inline (không semantic) |

## 🔹 2. TỔNG HỢP CÁC THUỘC TÍNH CSS QUAN TRỌNG

### Màu sắc và nền

| Thuộc tính | Ý nghĩa | Ví dụ |
|-----------|---------|-------|
| `color` | Màu chữ | `color: red;` |
| `background-color` | Màu nền | `background-color: #f0f4f8;` |

### Phông chữ và văn bản

| Thuộc tính | Ý nghĩa | Ví dụ |
|-----------|---------|-------|
| `font-family` | Phông chữ | `font-family: Arial, sans-serif;` |
| `font-size` | Cỡ chữ | `font-size: 16px;` |
| `font-weight` | Độ đậm | `font-weight: bold;` |
| `text-align` | Căn chỉnh chữ | `text-align: center;` |
| `text-decoration` | Trang trí chữ | `text-decoration: none;` (bỏ gạch chân) |

### Box Model

| Thuộc tính | Ý nghĩa | Ví dụ |
|-----------|---------|-------|
| `width` / `height` | Chiều rộng / cao | `width: 300px;` |
| `padding` | Khoảng cách bên trong viền | `padding: 10px 20px;` |
| `margin` | Khoảng cách bên ngoài viền | `margin: 0 auto;` |
| `border` | Đường viền | `border: 1px solid black;` |
| `border-radius` | Bo tròn góc | `border-radius: 8px;` |

### Bố cục

| Thuộc tính | Ý nghĩa | Ví dụ |
|-----------|---------|-------|
| `display` | Cách hiển thị | `display: block/inline/inline-block/none;` |
| `position` | Cách định vị | `position: relative/absolute/fixed;` |
| `top/right/bottom/left` | Khoảng cách khi position | `top: 10px; right: 20px;` |
| `float` | Nổi trái/phải | `float: left;` |

### CSS Selectors

| Selector | Cú pháp | Chọn cái gì |
|----------|---------|------------|
| Thẻ | `p { }` | Tất cả `<p>` |
| Class | `.ten-class { }` | Tất cả có `class="ten-class"` |
| ID | `#ten-id { }` | Phần tử có `id="ten-id"` |
| Lồng nhau | `ul li { }` | `<li>` bên trong `<ul>` |
| Hover | `a:hover { }` | Khi di chuột vào |

## 🔹 3. SƠ ĐỒ CẤU TRÚC TRANG WEB HOÀN CHỈNH

```
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>Tên trang</title>
    <link rel="stylesheet" href="style.css">
                    ↑ hoặc <style>...</style>
  </head>
  <body>
    <header>     ← Logo, tên website
    <nav>        ← Menu điều hướng
    <main>
      <section>  ← Mục nội dung
      <article>  ← Bài viết
      <aside>    ← Sidebar
    <footer>     ← Chân trang
  </body>
</html>
```

### Phần A – Câu hỏi trắc nghiệm lý thuyết

**Câu 1:** Thẻ nào **không** tự đóng (cần thẻ đóng)?

**A.** `<img>`  
**B.** `<input>`  
**C.** `<br>`  
**D.** `<textarea>`

> **Đáp án: D** – `<textarea>` cần thẻ đóng `</textarea>`. `<img>`, `<input>`, `<br>` đều là thẻ tự đóng.

**Câu 2:** Để liên kết mở trong **tab mới**, thuộc tính và giá trị nào cần thêm vào thẻ `<a>`?

**A.** `method="_blank"`  
**B.** `target="_blank"`  
**C.** `href="_blank"`  
**D.** `open="new"`

> **Đáp án: B** – `target="_blank"` chỉ định liên kết mở trong tab mới.

---

**Câu 3:** Trong CSS, `padding: 10px 20px` có nghĩa là:

**A.** Trên/dưới: 10px, Trái/phải: 20px  
**B.** Trên: 10px, Phải: 20px, Dưới: 10px, Trái: 20px  
**C.** Trái/phải: 10px, Trên/dưới: 20px  
**D.** Padding 10px trên tất cả 4 cạnh, sau đó 20px

> **Đáp án: A** – Khi `padding` có 2 giá trị: giá trị đầu là trên/dưới (10px), giá trị sau là trái/phải (20px).

**Câu 4:** Thẻ nào dùng để tạo **danh sách có đánh số thứ tự**?

**A.** `<ul>`  
**B.** `<li>`  
**C.** `<ol>`  
**D.** `<dl>`

> **Đáp án: C** – `<ol>` (Ordered List) tạo danh sách đánh số 1, 2, 3...

**Câu 5:** Trong bảng HTML, thẻ nào tạo **ô tiêu đề** với chữ tự động in đậm và căn giữa?

**A.** `<td>`  
**B.** `<tr>`  
**C.** `<caption>`  
**D.** `<th>`

> **Đáp án: D** – `<th>` (Table Header) tự động in đậm và căn giữa.

**Câu 6:** Selector CSS nào chọn tất cả phần tử có `class="noi-bat"`?

**Câu 7:** Thuộc tính nào của `<form>` xác định **địa chỉ nhận dữ liệu** khi submit?

**Câu 8:** `colspan="3"` trong `<td>` có nghĩa là:

**A.** Ô đó nằm ở cột thứ 3

### Phần B – Câu hỏi phân tích mã

**Câu 9:** Đoạn mã HTML sau tạo ra gì? Có lỗi không?

```html
<form method="post">
  <input type="text" placeholder="Tên bạn">
  <input type="submit" value="Gửi">
</form>
```

> **Đáp án:** Tạo form với ô nhập tên và nút gửi.
> **Có một vấn đề:** `<input type="text">` thiếu thuộc tính `name` → dữ liệu sẽ không được gửi đi khi submit.
> **Sửa lại:** Thêm `name="ten"` vào input.

---

**Câu 10:** Đoạn CSS sau có tác dụng gì?

```css
.the-bai {
  width: 600px;
  margin: 20px auto;
  padding: 15px;
  border: 1px solid #ccc;
  border-radius: 10px;
}
```

> **Đáp án:**
> - `width: 600px` → phần tử rộng 600px
> - `margin: 20px auto` → 20px cách trên/dưới, tự động căn giữa trang theo chiều ngang
> - `padding: 15px` → khoảng cách 15px từ viền vào nội dung bên trong
> - `border: 1px solid #ccc` → viền màu xám nhạt, đường liền, dày 1px
> - `border-radius: 10px` → bo tròn bốn góc 10px
> → Kết quả: hộp nội dung đẹp, căn giữa trang, có viền bo tròn.

## 🔹 5. BẢNG SO SÁNH NHANH – CÁC CẶP DỄ NHẦM

| Cặp | Điểm phân biệt chính |
|-----|---------------------|
| `<ul>` vs `<ol>` | `ul` = dấu chấm (không thứ tự); `ol` = đánh số (có thứ tự) |
| `<th>` vs `<td>` | `th` = tiêu đề (đậm, giữa); `td` = dữ liệu thường |
| `colspan` vs `rowspan` | `colspan` = gộp cột ngang; `rowspan` = gộp hàng dọc |
| `<input>` vs `<textarea>` | `input` = 1 dòng, tự đóng; `textarea` = nhiều dòng, có thẻ đóng |
| `radio` vs `checkbox` | `radio` = chọn 1; `checkbox` = chọn nhiều |
| `<div>` vs `<span>` | `div` = block (xuống dòng); `span` = inline (trong dòng) |
| `margin` vs `padding` | `margin` = ngoài viền; `padding` = trong viền |
| `href` vs `src` | `href` = đích liên kết `<a>`; `src` = nguồn ảnh `<img>` |
| `<strong>` vs `<b>` | `strong` = đậm + có nghĩa; `b` = chỉ đậm trình bày |
| `GET` vs `POST` | `GET` = hiện trên URL; `POST` = ẩn trong request |
| `display:none` vs `visibility:hidden` | `none` = ẩn không chiếm chỗ; `hidden` = ẩn vẫn chiếm chỗ |
| `position: relative` vs `absolute` | `relative` = giữ chỗ; `absolute` = lấy khỏi luồng |

## 🔹 6. GHI NHỚ NHANH TỔNG HỢP (ĐI THI)

**HTML:**
- ✅ Cấu trúc bắt buộc: `<!DOCTYPE html>` → `<html>` → `<head>` + `<body>`
- ✅ `<meta charset="UTF-8">` → **trong `<head>`**, hỗ trợ tiếng Việt
- ✅ `<title>` → hiển thị trên **tab trình duyệt**, không trong trang
- ✅ `<img>`, `<input>`, `<br>`, `<hr>` → thẻ **tự đóng**
- ✅ Bảng: `table > tr > th/td`; `colspan` = ngang; `rowspan` = dọc
- ✅ Form: cần `name` trên mọi input để gửi dữ liệu
- ✅ `<a href="url">` / `target="_blank"` / `href="mailto:"` / `href="#id"`

**CSS:**
- ✅ Selector: `thẻ { }` / `.class { }` / `#id { }` / `cha con { }`
- ✅ Box Model: **Content → Padding → Border → Margin** (trong → ngoài)
- ✅ `margin: 0 auto` + `width` → căn giữa block
- ✅ `padding` = trong viền (có nền); `margin` = ngoài viền (trong suốt)
- ✅ `display: none` → ẩn; `block` → chiếm hàng; `inline-block` → trong dòng có width/height
- ✅ `position: fixed` → cố định màn hình; `absolute` → theo cha có `position: relative`
