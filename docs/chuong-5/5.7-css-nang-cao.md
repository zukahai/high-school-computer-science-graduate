# Mục 5.7 – CSS Nâng Cao: Box Model, Display, Position

---

## 🔹 1. GIỚI THIỆU SIÊU CƠ BẢN

**Tại sao cần hiểu sâu hơn về CSS?**

Bạn đã biết CSS cơ bản: màu sắc, font chữ, viền. Nhưng làm sao để:
- Căn giữa một hộp nội dung trên trang?
- Đặt ảnh nổi bên phải, chữ chạy vòng quanh bên trái?
- Tạo menu nằm ngang thay vì xếp dọc?
- Đặt nút "Lên đầu trang" luôn cố định ở góc phải?

Đây là lúc cần **Box Model**, **Display**, và **Position** – ba khái niệm nền tảng của bố cục CSS.

---

## 🔹 2. LÝ THUYẾT CHI TIẾT

### 2.1 – Box Model (Mô hình hộp)

Mọi phần tử HTML đều là một **hộp chữ nhật** gồm 4 lớp từ ngoài vào trong:

```
+-------------------------------+
|           margin              |  ← khoảng cách bên NGOÀI viền
|  +-------------------------+  |
|  |        border           |  |  ← đường viền
|  |  +-------------------+  |  |
|  |  |     padding       |  |  |  ← khoảng cách bên TRONG viền
|  |  |  +-------------+  |  |  |
|  |  |  |   content   |  |  |  |  ← nội dung thực (chữ, ảnh)
|  |  |  +-------------+  |  |  |
|  |  +-------------------+  |  |
|  +-------------------------+  |
+-------------------------------+
```

**Các thuộc tính:**

| Thuộc tính | Ý nghĩa | Ví dụ |
|-----------|---------|-------|
| `margin` | Khoảng cách bên **ngoài** viền (đẩy phần tử khác ra xa) | `margin: 20px` |
| `border` | Đường **viền** bao quanh | `border: 1px solid black` |
| `padding` | Khoảng cách bên **trong** viền (giữa viền và nội dung) | `padding: 10px` |
| `width` | Chiều rộng vùng **nội dung** | `width: 300px` |
| `height` | Chiều cao vùng **nội dung** | `height: 150px` |

**Cách viết shorthand (rút gọn):**

```css
/* Cả 4 cạnh bằng nhau */
margin: 10px;

/* trên/dưới  trái/phải */
margin: 10px 20px;

/* trên  trái/phải  dưới */
margin: 5px 15px 10px;

/* trên  phải  dưới  trái (theo chiều kim đồng hồ) */
margin: 5px 10px 15px 20px;
```

**Tip quan trọng:** `margin: 0 auto` → căn giữa block element theo chiều ngang (khi có `width` cố định).

---

### 2.2 – Thuộc tính `display`

`display` xác định cách phần tử hiển thị và chiếm không gian.

| Giá trị | Ý nghĩa |
|---------|---------|
| `block` | Chiếm cả hàng ngang, xuống dòng (mặc định của `<div>`, `<p>`, `<h1>`...) |
| `inline` | Nằm trong dòng chữ, không đặt được `width`/`height` (mặc định của `<span>`, `<a>`...) |
| `inline-block` | Nằm trong dòng, nhưng có thể đặt `width`/`height` |
| `none` | Ẩn phần tử hoàn toàn (không chiếm không gian) |
| `flex` | Bố cục linh hoạt Flexbox (hiện đại) |

---

### 2.3 – Thuộc tính `position`

`position` xác định cách đặt vị trí phần tử trong trang.

| Giá trị | Ý nghĩa |
|---------|---------|
| `static` | Mặc định – theo luồng bình thường |
| `relative` | Dịch chuyển **so với vị trí gốc** của nó (giữ nguyên chỗ trong luồng) |
| `absolute` | Đặt vị trí **so với phần tử cha** có `position` khác `static` |
| `fixed` | **Cố định trên màn hình** – không cuộn theo trang |
| `sticky` | Cuộn bình thường rồi **dính** khi đến vị trí chỉ định |

**Đi kèm với** `position` (trừ `static`) là: `top`, `right`, `bottom`, `left` để chỉ khoảng cách.

```css
.nut-len-dau {
  position: fixed;
  bottom: 20px;
  right: 20px;
}
```

---

### 2.4 – Thuộc tính `float`

`float` làm phần tử "nổi" sang trái hoặc phải, cho phép nội dung khác chạy vòng quanh.

```css
img {
  float: left;
  margin-right: 15px;
}
```

| Giá trị | Ý nghĩa |
|---------|---------|
| `left` | Nổi sang trái |
| `right` | Nổi sang phải |
| `none` | Không nổi (mặc định) |

## 🔹 3. GIẢI THÍCH BẢN CHẤT

### Box Model bằng ví dụ thực tế

Hình dung một **bức tranh treo tường**:
- **Content** = bức tranh thực sự (nội dung)
- **Padding** = khoảng trắng giữa tranh và khung gỗ
- **Border** = khung gỗ bao quanh
- **Margin** = khoảng cách từ khung gỗ ra đến tường (cách bức tranh bên cạnh)

### `margin` vs `padding` – Dễ nhầm nhất!

| | `margin` | `padding` |
|--|---------|---------|
| Vị trí | Bên **ngoài** border | Bên **trong** border |
| Ảnh hưởng background | Không (vùng margin trong suốt) | Có (background-color lan vào padding) |
| Nhớ nhanh | **Margin** = Mặt **ngoài** | **Padding** = **Phía trong** |

### Tại sao cần `position: relative` cho cha khi dùng `absolute` cho con?

`absolute` tìm phần tử cha **gần nhất** có `position` khác `static` để định vị. Nếu không có, nó định vị theo `<body>`. Bài học: luôn đặt `position: relative` cho thẻ cha khi muốn con dùng `absolute`.

## 🔹 4. LUỒNG HOẠT ĐỘNG STEP-BY-STEP

**Trình duyệt tính toán kích thước và vị trí phần tử:**

1. **Tính `content` size** → từ `width` và `height` (hoặc nội dung bên trong)
2. **Cộng `padding`** → tăng vùng nền màu bên trong
3. **Cộng `border`** → vẽ viền bao ngoài
4. **Cộng `margin`** → tạo khoảng cách với phần tử lân cận
5. **Tổng chiều rộng thực = content + padding trái/phải + border trái/phải + margin trái/phải**
6. **Áp dụng `display`** → block/inline/flex...
7. **Áp dụng `position`** → đặt phần tử đúng vị trí

## 🔹 5. VÍ DỤ MINH HỌA

### Ví dụ 1 – Box Model trực quan

```html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>Box Model</title>
    <style>
      .hop {
        width: 200px;
        height: 100px;
        background-color: #bbdefb;
        padding: 20px;
        border: 3px solid #1565c0;
        margin: 30px auto;
      }
    </style>
  </head>
  <body>
    <div class="hop">
      Nội dung bên trong hộp
    </div>
  </body>
</html>
```

**Phân tích kích thước thực:**
- Content: 200px × 100px
- Padding: +20px mỗi bên → rộng thực = 200 + 40 = 240px
- Border: +3px mỗi bên → rộng thực = 240 + 6 = 246px
- Margin: 30px trên/dưới, `auto` trái/phải → căn giữa trang

---

### Ví dụ 2 – Display: Tạo menu nằm ngang

```html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>Menu ngang</title>
    <style>
      nav {
        background-color: #1a73e8;
        padding: 10px;
      }
      nav a {
        display: inline-block;
        color: white;
        text-decoration: none;
        padding: 8px 16px;
        margin-right: 5px;
        border-radius: 4px;
      }
      nav a:hover {
        background-color: #1557b0;
      }
    </style>
  </head>
  <body>
    <nav>
      <a href="#">Trang chủ</a>
      <a href="#">Tin tức</a>
      <a href="#">Về chúng tôi</a>
      <a href="#">Liên hệ</a>
    </nav>
  </body>
</html>
```

**Giải thích:**
- Mặc định `<a>` là `inline` → không đặt được `padding` đầy đủ
- `display: inline-block` → vừa nằm trên cùng dòng, vừa đặt được `padding`/`width`
- `:hover` → pseudo-class CSS, áp dụng khi di chuột vào

---

### Ví dụ 3 – Position: Nút cố định góc màn hình

```html
<!DOCTYPE html>
<html lang="vi">
  <head>
    <meta charset="UTF-8">
    <title>Position</title>
    <style>
      body { height: 2000px; font-family: Arial; padding: 20px; }

      /* Hộp định vị tương đối */
      .container {
        position: relative;
        width: 400px;
        height: 200px;
        background-color: #e8f5e9;
        border: 2px solid #388e3c;
        padding: 10px;
      }
      /* Badge góc trên phải hộp */
      .badge {
        position: absolute;
        top: -10px;
        right: -10px;
        background-color: red;
        color: white;
        padding: 5px 10px;
        border-radius: 50%;
        font-size: 12px;
      }

      /* Nút cố định góc màn hình */
      .nut-len-dau {
        position: fixed;
        bottom: 30px;
        right: 30px;
        background-color: #1a73e8;
        color: white;
        padding: 10px 15px;
        border-radius: 50%;
        text-decoration: none;
        font-size: 18px;
      }
    </style>
  </head>
  <body>
    <div class="container">
      <p>Hộp nội dung có badge góc</p>
      <span class="badge">Mới</span>
    </div>

    <p>Cuộn trang xuống để thấy nút cố định...</p>

    <a href="#" class="nut-len-dau">↑</a>
  </body>
</html>
```

**Giải thích:**
- `.container { position: relative }` → làm mốc định vị cho `.badge`
- `.badge { position: absolute; top: -10px; right: -10px }` → nhô ra ngoài góc hộp 10px
- `.nut-len-dau { position: fixed; bottom: 30px; right: 30px }` → luôn ở góc phải dưới màn hình dù cuộn trang

## 🔹 6. SO SÁNH & PHÂN BIỆT

### So sánh `margin` và `padding`

| | `margin` | `padding` |
|--|---------|---------|
| Vị trí | Bên **ngoài** border | Bên **trong** border |
| Ảnh hưởng background | Không | Có |
| Dùng để | Cách xa phần tử khác | Tạo khoảng thở bên trong |
| `auto` | Căn giữa | Không có tác dụng |

### So sánh các giá trị `position`

| Giá trị | Vị trí gốc | Tham chiếu | Có chiếm chỗ? |
|---------|-----------|-----------|--------------|
| `static` | Luồng bình thường | – | Có |
| `relative` | Luồng bình thường | Chính nó | Có |
| `absolute` | Lấy ra khỏi luồng | Cha gần nhất có position | Không |
| `fixed` | Lấy ra khỏi luồng | Viewport (màn hình) | Không |

### So sánh `display: none` và `visibility: hidden`

| | `display: none` | `visibility: hidden` |
|--|----------------|---------------------|
| Phần tử ẩn? | Có | Có |
| Còn chiếm không gian? | Không | Có (chỗ trống vẫn còn) |

---

## 🔹 7. GHI NHỚ NHANH (ĐI THI)

- ✅ **Box Model** = Content → Padding → Border → Margin (từ trong ra ngoài)
- ✅ `padding` = bên **trong** viền (nền màu); `margin` = bên **ngoài** viền (trong suốt)
- ✅ `margin: 0 auto` + `width` cố định = **căn giữa** block element
- ✅ `display: block` → chiếm hàng ngang; `inline` → trong dòng; `none` → ẩn hẳn
- ✅ `display: inline-block` → trong dòng **nhưng** đặt được width/height/padding
- ✅ `position: fixed` → **cố định** trên màn hình, không cuộn
- ✅ `position: absolute` → định vị theo phần tử cha có `position: relative`
- ✅ `float: left/right` → phần tử nổi, nội dung khác chạy vòng quanh

## 🔹 8. BÀI TẬP TỰ LUYỆN

### Câu 1 (Dễ): Sắp xếp từ ngoài vào trong các lớp của Box Model.

> **Đáp án:** **Margin → Border → Padding → Content** (từ ngoài vào trong).

---

### Câu 2 (Dễ): Viết CSS để một `<div>` rộng 300px được căn giữa trang.

> **Đáp án:**
> ```css
> div {
>   width: 300px;
>   margin: 0 auto;
> }
> ```

---

### Câu 3 (Trung bình): Đoạn CSS sau tạo hộp có kích thước thực (kể cả padding và border) là bao nhiêu?

```css
.hop {
  width: 200px;
  height: 100px;
  padding: 10px;
  border: 2px solid black;
}
```

> **Đáp án:**
> - Chiều rộng thực = 200 + 10×2 (padding) + 2×2 (border) = **224px**
> - Chiều cao thực = 100 + 10×2 (padding) + 2×2 (border) = **124px**

---

### Câu 4 (Trung bình): Sự khác nhau giữa `position: relative` và `position: absolute` là gì?

> **Đáp án:**
> - `relative`: Phần tử **vẫn giữ chỗ** trong luồng, chỉ bị dịch chuyển *trực quan* so với vị trí gốc của nó. Các phần tử xung quanh không bị ảnh hưởng.
> - `absolute`: Phần tử **bị lấy ra khỏi luồng** hoàn toàn. Được định vị so với phần tử cha gần nhất có `position` khác `static`. Không chiếm chỗ trong layout.

---

### Câu 5 (Vận dụng): Viết CSS cho một `<div class="the-bai">` có: chiều rộng 500px, căn giữa trang, viền xanh dương 2px đường liền, padding 20px, margin trên/dưới 30px.

> **Đáp án:**
> ```css
> .the-bai {
>   width: 500px;
>   margin: 30px auto;
>   border: 2px solid blue;
>   padding: 20px;
> }
> ```

## 🔹 9. LỖI THƯỜNG GẶP

| Lỗi | Ví dụ sai | Sửa lại | Hậu quả |
|-----|-----------|---------|---------|
| Nhầm `margin` và `padding` | Dùng `margin: 20px` muốn tạo khoảng trong | Dùng `padding: 20px` | Khoảng cách không theo ý, background không đúng |
| Quên `width` khi dùng `margin: auto` | Không có `width`, dùng `margin: 0 auto` | Thêm `width: Xpx` | Block không căn giữa được |
| `position: absolute` không theo ý | Hộp con định vị theo `<body>` | Đặt `position: relative` cho cha | Badge/popup xuất hiện sai vị trí |
| `display: none` thay vì `visibility: hidden` | Dùng `display:none` nhưng muốn giữ chỗ | Dùng `visibility: hidden` | Phần tử ẩn nhưng layout bị xê dịch |
| `float` không hoạt động như mong muốn | Phần tử cha bị "sụp" | Dùng `overflow: auto` cho cha | Layout bị vỡ |
| Nhầm `box-sizing: content-box` và `border-box` | `width: 200px` nhưng tổng chiều rộng thực lớn hơn | Thêm `box-sizing: border-box` để `width` bao gồm cả padding và border | Kích thước không như mong muốn, layout lệch |
| Quên `width` khi dùng `display: flex` | `div { display: flex; }` không đặt kích thước | Đặt `width` hoặc `flex-basis` cho các flex item | Flex item co lại hoặc giãn ra không đều |
| Dùng `position: absolute` mà không đặt `top`/`left` | `.badge { position: absolute; }` không có tọa độ | Thêm `top: 0; right: 0;` hoặc các giá trị phù hợp | Phần tử xuất hiện tại vị trí gốc trước khi bị lấy ra khỏi luồng |
| Nhầm `position: sticky` với `position: fixed` | Dùng `fixed` nhưng muốn phần tử dính khi cuộn theo section | `sticky` dính trong phạm vi cha; `fixed` cố định theo viewport | Phần tử dính ở sai vị trí hoặc không dính |
| Dùng `z-index` mà không có `position` | `.hop { z-index: 10; }` không có `position` | Thêm `position: relative` hoặc `absolute` | `z-index` không có tác dụng với `position: static` |
| `z-index` cao nhưng phần tử vẫn bị che | `z-index: 9999` nhưng vẫn bị che bởi phần tử khác | Kiểm tra stacking context: `z-index` chỉ so sánh trong cùng stacking context | Phần tử không nổi lên như mong muốn |
| Dùng `flexbox` sai trục | Muốn các item xếp dọc nhưng dùng `flex-direction: row` | `flex-direction: column` để xếp dọc | Các item xếp ngang thay vì dọc |
| Quên `flex-wrap: wrap` cho flex container | Nhiều item bị tràn ra ngoài thay vì xuống hàng | Thêm `flex-wrap: wrap;` vào flex container | Tất cả item ép trên một hàng, tràn container |
| Nhầm `justify-content` và `align-items` trong flexbox | Muốn căn giữa theo chiều dọc nhưng dùng `justify-content: center` | `align-items: center` căn theo trục phụ (dọc khi row); `justify-content: center` theo trục chính (ngang) | Phần tử căn giữa sai chiều |
| Quên đặt `height` cho flex container khi căn dọc | `align-items: center` không có tác dụng | Đặt `height: 100vh` hoặc chiều cao cố định cho container | Không có không gian để căn giữa theo chiều dọc |
| Dùng `gap` trong flexbox cũ | Dùng `gap: 20px;` nhưng trình duyệt cũ không hỗ trợ | Thêm `margin` dự phòng hoặc kiểm tra trình duyệt cần hỗ trợ | Khoảng cách giữa item biến mất trên trình duyệt cũ |
| Nhầm `grid-template-columns` và `grid-template-rows` | Muốn tạo 3 cột nhưng dùng `grid-template-rows: repeat(3, 1fr)` | `grid-template-columns: repeat(3, 1fr)` cho 3 cột | Grid có 3 hàng thay vì 3 cột |
| Dùng `fr` unit sai trong grid | `grid-template-columns: 1fr 200px 1fr` nhưng muốn 3 cột bằng nhau | `grid-template-columns: repeat(3, 1fr)` cho 3 cột bằng nhau | Cột không đều như mong muốn |
| Không dùng `transition` khi cần animation mượt | Màu nền thay đổi ngay lập tức khi hover | `transition: background-color 0.3s ease;` | Hiệu ứng bị giật, không mượt mà |
| Quên `transform-origin` khi dùng `transform: rotate()` | `div { transform: rotate(45deg); }` quay quanh tâm mặc định | `transform-origin: top left;` để quay quanh góc trên trái | Phần tử quay quanh điểm không mong muốn |
| Dùng `margin: auto` cho flex item theo chiều dọc mà quên `height` | Flex item với `margin: auto` không căn giữa theo chiều dọc | Đặt chiều cao cho flex container hoặc dùng `align-items: center` | Auto margin không hoạt động nếu không có không gian dọc |
| Nhầm `transform: translate` đơn vị | `transform: translate(50%, 50%)` (% tính theo bản thân phần tử) | Hiểu `%` trong `translate` tính theo kích thước của chính phần tử, không phải cha | Phần tử dịch chuyển không đúng vị trí mong muốn |
| Dùng `width: 100vw` gây thanh cuộn ngang | `body { width: 100vw; }` | Dùng `width: 100%` cho `body` | `100vw` bao gồm cả chiều rộng scrollbar, gây tràn |
| Không dùng `min-width` và `max-width` cho responsive | Phần tử quá rộng trên màn hình lớn, quá hẹp trên màn hình nhỏ | `max-width: 1200px; min-width: 320px;` | Layout vỡ trên các kích thước màn hình cực đoan |
| Dùng `px` thay `em`/`rem` cho media query | `@media (max-width: 768px)` thay vì `@media (max-width: 48em)` | Dùng `em` trong media query để tôn trọng cài đặt font người dùng | Breakpoint cố định, không responsive với cài đặt font |
