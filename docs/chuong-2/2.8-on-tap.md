## 🔹 4. ĐỀ LUYỆN SỐ 2 – PHÂN TÍCH TÌNH HUỐNG

### Câu 1: Phân tích lỗi mạng
> Một học sinh báo: "Em không vào được Internet nhưng vẫn in được tài liệu qua máy in mạng trong trường." Xác định:
> a) Tầng OSI nào có khả năng bị lỗi?
> b) Nguyên nhân có thể là gì?

**Đáp án:**

**a) Tầng có khả năng bị lỗi:** Tầng 3 (Network) trở lên.

**Lý do:** In qua mạng nội bộ vẫn được → Tầng 1 (Physical), Tầng 2 (Data Link) và kết nối LAN nội bộ hoạt động bình thường. Lỗi xảy ra khi dữ liệu cần ra khỏi LAN (qua Router ra Internet) → vấn đề ở Tầng 3.

**b) Nguyên nhân có thể:**
- Default gateway (địa chỉ IP của Router) chưa được cấu hình đúng.
- Router bị lỗi hoặc chưa kết nối với ISP.
- IP của học sinh nằm ngoài dải IP được phép của trường.
- Firewall của trường chặn kết nối Internet từ máy đó.

---

### Câu 2: Lựa chọn giao thức
> Hãy chọn giao thức phù hợp cho từng tình huống và giải thích:
> a) Truyền trực tiếp kết quả thi đấu thể thao thời gian thực (live score)
> b) Gửi file hợp đồng PDF quan trọng qua Internet
> c) Tải website ngân hàng
> d) Chuyển file lớn lên server hosting

**Đáp án:**

| Tình huống | Giao thức | Lý do |
|---|---|---|
| a) Live score thời gian thực | UDP | Cần tốc độ, chấp nhận mất vài gói dữ liệu cũ |
| b) Gửi file PDF hợp đồng | TCP (qua email SMTP) | Phải đảm bảo file đến đủ, không mất byte |
| c) Tải website ngân hàng | HTTPS (TCP) | Cần mã hóa bảo mật + đảm bảo tải đủ trang |
| d) Chuyển file lên server | FTP/SFTP | Giao thức thiết kế cho truyền file |

### Câu 3: Phân tích bảo mật
> Nhà trường nhận được nhiều email có chủ đề "Kết quả thi của em đã có" từ địa chỉ lạ, kèm file đính kèm. Một giáo viên đã mở file đính kèm và sau đó toàn bộ file bài giảng trên máy đó bị mã hóa, có thông báo đòi tiền chuộc.
> a) Đây là loại tấn công gì?
> b) Giải thích cơ chế tấn công.
> c) Nhà trường nên làm gì để khắc phục và phòng tránh trong tương lai?

**Đáp án:**

**a) Loại tấn công:** Phishing + Ransomware.

**b) Cơ chế:**
- Hacker gửi email **phishing** giả mạo, đính kèm file chứa **Ransomware** (có thể ẩn trong file .docx, .pdf, .exe giả mạo).
- Giáo viên bị lừa mở file → Ransomware tự chạy trên máy.
- Ransomware **mã hóa tất cả file** trên máy (và có thể cả thư mục mạng được share).
- Hiển thị thông báo đòi tiền chuộc (thường bằng Bitcoin) để cung cấp khóa giải mã.

**c) Khắc phục và phòng tránh:**

| Hành động | Mục đích |
|---|---|
| **Ngắt kết nối mạng ngay** | Ngăn ransomware lây sang máy khác qua mạng |
| **Khôi phục từ bản backup** | Lấy lại dữ liệu (nếu đã backup trước) |
| **Quét toàn bộ hệ thống** bằng antivirus | Loại bỏ ransomware |
| **Đào tạo nhận thức** cho giáo viên về phishing | Phòng tránh tương lai |
| **Không mở file đính kèm** từ email không rõ nguồn gốc | Phòng tránh |
| **Sao lưu định kỳ** (backup 3-2-1) | Phục hồi khi bị tấn công lần sau |
| **Cài antivirus, cập nhật** thường xuyên | Phát hiện malware mới |

### Câu 2: Phân tích địa chỉ IP

> Cho địa chỉ IP `10.0.5.200`:
> a) Đây là IP công cộng hay IP riêng tư? Vì sao?
> b) Thiết bị này có thể truy cập Internet trực tiếp không? Vì sao?
> c) Để ra Internet, cần cơ chế gì?

**Đáp án:**

**a) IP riêng tư (Private IP)**
Dải `10.0.0.0 – 10.255.255.255` là một trong ba dải địa chỉ riêng tư theo RFC 1918, không được định tuyến trên Internet công cộng.

**b) Không thể truy cập Internet trực tiếp**
IP riêng tư không được định tuyến trên Internet – các Router trên Internet sẽ **không biết** cách chuyển gói tin về địa chỉ `10.0.5.200`.

**c) Cần NAT (Network Address Translation)**
Router sẽ dùng NAT để **dịch địa chỉ IP riêng tư** (`10.0.5.200`) sang **IP công cộng** (do ISP cấp) khi gói tin ra Internet. Khi gói tin trả về, Router dịch ngược lại IP công cộng → IP riêng tư và chuyển đến thiết bị đúng.

## 🔹 6. BẢNG GHI NHỚ TỔNG HỢP – ĐI THI

### ⚡ Những điều CHẮC CHẮN ra thi

| Chủ đề | Điều cần nhớ |
|---|---|
| **Switch** | Tầng 2, dùng địa chỉ **MAC**, kết nối trong **LAN** |
| **Router** | Tầng 3, dùng địa chỉ **IP**, kết nối **giữa các mạng** |
| **Modem** | Chuyển đổi tín hiệu **số ↔ analog**, kết nối với **ISP** |
| **TCP** | Tin cậy, có **ACK**, **3-way handshake**, dùng cho web/email |
| **UDP** | Nhanh, **không ACK**, dùng cho game/video call |
| **IPv4** | **32 bit**, dạng `X.X.X.X`, private: `192.168.x.x` |
| **OSI Tầng 7** | Application: **HTTP, HTTPS, FTP, SMTP, DNS** |
| **OSI Tầng 4** | Transport: **TCP/UDP**, đơn vị: **Segment** |
| **OSI Tầng 3** | Network: **IP**, thiết bị: **Router**, đơn vị: **Packet** |
| **OSI Tầng 2** | Data Link: **MAC**, thiết bị: **Switch**, đơn vị: **Frame** |
| **OSI Tầng 1** | Physical: **Bit**, thiết bị: **Hub, cáp** |
| **SMTP** | **Gửi** email, cổng **25/587** |
| **IMAP** | **Nhận** email, **đồng bộ nhiều thiết bị**, cổng **143/993** |
| **POP3** | **Nhận** email, tải về **xóa server**, cổng **110/995** |
| **FTP** | **Truyền file**, cổng **21** |
| **HTTPS** | HTTP + mã hóa **SSL/TLS**, cổng **443** |
| **DNS** | Dịch **tên miền → IP**, cổng **53** |
| **Worm** | **Tự lan qua mạng**, không cần người dùng |
| **Virus** | **Gắn vào file**, cần người dùng chạy |
| **Ransomware** | **Mã hóa dữ liệu**, đòi tiền chuộc |
| **Phishing** | **Giả mạo** tổ chức uy tín, lừa lấy thông tin |
| **Firewall** | **Kiểm soát luồng** dữ liệu vào/ra theo quy tắc |
| **LAN** | Tòa nhà, **Ethernet/Wi-Fi**, tốc độ cao |
| **WAN** | Toàn cầu, **Internet** |
| **Star topology** | Switch trung tâm, **phổ biến nhất** hiện nay |
| **Client-Server** | Server tập trung, **quản lý dễ**, bảo mật tốt |

## 🔹 7. CÁC CÂU HỎI THƯỜNG GẶP NHẤT TRONG ĐỀ THI

### ❓ Hỏi về thiết bị mạng

**Q: Switch dùng địa chỉ gì để chuyển dữ liệu?**
→ **MAC address** (địa chỉ vật lý).

**Q: Router dùng địa chỉ gì để định tuyến?**
→ **IP address** (địa chỉ logic).

**Q: Thiết bị nào kết nối mạng LAN với Internet?**
→ **Router** (kết hợp với Modem).

---

### ❓ Hỏi về TCP/IP và OSI

**Q: TCP khác UDP ở điểm gì quan trọng nhất?**
→ TCP **có ACK** (xác nhận và gửi lại nếu mất), UDP **không có ACK**.

**Q: Giao thức nào dùng để truyền file mà không thể mất dữ liệu?**
→ **TCP** (có cơ chế đảm bảo độ tin cậy).

**Q: Router hoạt động ở tầng mấy của OSI?**
→ **Tầng 3 (Network Layer)**.

**Q: Switch hoạt động ở tầng mấy của OSI?**
→ **Tầng 2 (Data Link Layer)**.

---

### ❓ Hỏi về dịch vụ Internet

**Q: SMTP, POP3, IMAP dùng để làm gì?**
→ SMTP: **gửi** email. POP3 + IMAP: **nhận** email (POP3 tải về xóa server, IMAP đồng bộ nhiều thiết bị).

**Q: DNS làm nhiệm vụ gì?**
→ **Dịch tên miền** (ví dụ `google.com`) **sang địa chỉ IP** (ví dụ `142.250.196.46`).

**Q: HTTPS khác HTTP ở điểm gì?**
→ HTTPS **mã hóa bằng SSL/TLS**, HTTP không mã hóa; HTTPS dùng cổng **443**, HTTP dùng cổng **80**.

---

### ❓ Hỏi về bảo mật

**Q: Phần mềm nào tự lan qua mạng không cần người dùng?**
→ **Worm** (khác với Virus cần gắn vào file và cần người dùng chạy).

**Q: Ransomware là gì?**
→ Phần mềm **mã hóa dữ liệu** của nạn nhân và **đòi tiền chuộc** để giải mã.

**Q: Phishing là gì?**
→ Kỹ thuật **giả mạo** tổ chức uy tín (ngân hàng, Google...) để **lừa lấy thông tin** (mật khẩu, số tài khoản...).

**Q: Firewall là gì?**
→ Hệ thống **kiểm soát luồng dữ liệu** vào/ra mạng, cho phép hoặc **chặn** dựa trên quy tắc.

---

### ❓ Hỏi về phân loại mạng

**Q: Sắp xếp theo phạm vi từ nhỏ đến lớn: LAN, WAN, MAN, PAN?**
→ **PAN < LAN < MAN < WAN**.

**Q: Topology nào phổ biến nhất trong mạng LAN văn phòng?**
→ **Star (hình sao)** – tất cả thiết bị kết nối vào Switch trung tâm.

**Q: Internet là loại mạng gì?**
→ **WAN** (Wide Area Network) – mạng diện rộng toàn cầu.
