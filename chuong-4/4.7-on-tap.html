Mục 4.7 – Ôn Tập Chương 4: Cơ Sở Dữ Liệu & SQL ​

Chương 4: Cơ sở dữ liệu và SQL

🔹 1. SƠ ĐỒ TỔNG QUAN CHƯƠNG 4 ​

🗄️ CƠ SỞ DỮ LIỆU & SQL
│
├── 4.1 CSDL VÀ DBMS
│     ├── CSDL = kho dữ liệu có tổ chức
│     ├── DBMS = phần mềm quản lý CSDL (MySQL, PostgreSQL, SQLite...)
│     ├── Bảng (Table) = hàng (row) + cột (column)
│     └── CSDL quan hệ (Relational Database)
│
├── 4.2 KHÓA CHÍNH & KHÓA NGOẠI
│     ├── Primary Key (PK) – duy nhất + không NULL
│     ├── Composite Primary Key – 2+ cột kết hợp
│     ├── Foreign Key (FK) – tham chiếu PK bảng khác
│     └── Toàn vẹn tham chiếu (Referential Integrity)
│
├── 4.3 SQL CƠ BẢN
│     ├── SELECT / FROM / WHERE
│     ├── INNER JOIN ... ON
│     ├── ORDER BY ASC/DESC
│     └── Toán tử: =, >, <, BETWEEN, LIKE, IN, AND, OR, NOT
│
├── 4.4 DDL – ĐỊNH NGHĨA CẤU TRÚC
│     ├── CREATE TABLE (tạo bảng)
│     ├── ALTER TABLE (sửa cấu trúc)
│     └── DROP TABLE (xóa bảng)
│
├── 4.5 DML – THAO TÁC DỮ LIỆU
│     ├── INSERT INTO (thêm dữ liệu)
│     ├── UPDATE ... SET ... WHERE (sửa dữ liệu)
│     └── DELETE FROM ... WHERE (xóa dữ liệu)
│
└── 4.6 SQL NÂNG CAO
      ├── Hàm tổng hợp: COUNT, SUM, AVG, MAX, MIN
      ├── GROUP BY (nhóm dữ liệu)
      ├── HAVING (lọc nhóm sau GROUP BY)
      ├── DISTINCT (loại bỏ trùng lặp)
      ├── LIMIT (giới hạn số hàng)
      └── LEFT JOIN / RIGHT JOIN

🔹 2. TÓM TẮT LÝ THUYẾT TOÀN CHƯƠNG ​

📌 Mục 4.1 – CSDL và DBMS ​

Khái niệmĐịnh nghĩa ngắn gọn
CSDL (Database)Tập hợp dữ liệu có tổ chức, lưu trên máy tính
DBMSPhần mềm quản lý CSDL (MySQL, PostgreSQL, SQLite, Oracle...)
Bảng (Table)Lưu dữ liệu dạng hàng và cột

Luồng hoạt động:

Ứng dụng (App) → DBMS → CSDL (file trên ổ cứng)

📌 Mục 4.4 – DDL (Data Definition Language) ​

CREATE TABLE:

sql
CREATE TABLE HocSinh (
    MaHS     INT          PRIMARY KEY,
    HoTen    VARCHAR(100) NOT NULL,
    NgaySinh DATE,
    MaLop    VARCHAR(10)  NOT NULL,
    FOREIGN KEY (MaLop) REFERENCES Lop(MaLop)
);

ALTER TABLE:

sql
-- Thêm cột
ALTER TABLE HocSinh ADD Email VARCHAR(100);

-- Sửa kiểu dữ liệu cột
ALTER TABLE HocSinh MODIFY HoTen VARCHAR(150) NOT NULL;

-- Xóa cột
ALTER TABLE HocSinh DROP COLUMN Email;

DROP TABLE:

sql
DROP TABLE HocSinh;            -- Xóa cả bảng
TRUNCATE TABLE HocSinh;        -- Xóa toàn bộ dữ liệu, giữ cấu trúc

📌 Mục 4.5 – DML (Data Manipulation Language) ​

INSERT INTO:

sql
-- Thêm một hàng
INSERT INTO HocSinh (MaHS, HoTen, MaLop)
VALUES (1, 'Nguyễn Văn An', '10A');

-- Thêm nhiều hàng cùng lúc
INSERT INTO HocSinh (MaHS, HoTen, MaLop) VALUES
    (2, 'Trần Thị Bình', '10A'),
    (3, 'Lê Văn Cường', '10B');

UPDATE:

sql
-- Sửa điểm học sinh cụ thể (LUÔN CÓ WHERE!)
UPDATE DiemThi
SET Diem = 9.5
WHERE MaHS = 1 AND MaMon = 'TOAN';

DELETE:

sql
-- Xóa học sinh cụ thể (LUÔN CÓ WHERE!)
DELETE FROM HocSinh WHERE MaHS = 5;

⚠️ Cảnh báo: UPDATE và DELETE không có WHERE sẽ ảnh hưởng toàn bộ bảng!

📌 Mục 4.6 – SQL Nâng Cao ​

Hàm tổng hợp:

HàmÝ nghĩaVí dụ kết quả
COUNT(*)Đếm số hàng30 học sinh
SUM(Diem)Tổng điểm240.5
AVG(Diem)Điểm trung bình8.02
MAX(Diem)Điểm cao nhất10.0
MIN(Diem)Điểm thấp nhất4.0

GROUP BY + HAVING:

sql
-- Đếm số học sinh theo từng lớp
SELECT MaLop, COUNT(*) AS SoHocSinh
FROM HocSinh
GROUP BY MaLop;

-- Chỉ lấy lớp có trên 30 học sinh
SELECT MaLop, COUNT(*) AS SoHocSinh
FROM HocSinh
GROUP BY MaLop
HAVING COUNT(*) > 30;

LEFT JOIN:

sql
-- Hiển thị TẤT CẢ học sinh, kể cả chưa có điểm
SELECT hs.HoTen, dt.Diem
FROM HocSinh hs
LEFT JOIN DiemThi dt ON hs.MaHS = dt.MaHS;

DISTINCT và LIMIT:

sql
SELECT DISTINCT MaLop FROM HocSinh;           -- Danh sách lớp không trùng
SELECT * FROM HocSinh ORDER BY HoTen LIMIT 10; -- 10 học sinh đầu tiên

🔹 5. BÀI TẬP TỔNG HỢP CHƯƠNG 4 ​

Dữ liệu mẫu:

sql
-- Bảng Lop
MaLop | TenLop
------+-------
10A   | Lớp 10A
10B   | Lớp 10B
11A   | Lớp 11A

-- Bảng HocSinh
MaHS | HoTen              | MaLop
-----+--------------------+------
1    | Nguyễn Văn An      | 10A
2    | Trần Thị Bình      | 10A
3    | Lê Văn Cường       | 10B
4    | Phạm Thị Dung      | 11A
5    | Hoàng Minh Đức     | 10B

-- Bảng DiemThi
MaHS | MaMon | Diem
-----+-------+-----
1    | TOAN  | 9.0
1    | VAN   | 8.0
2    | TOAN  | 7.5
3    | TOAN  | 8.5
3    | VAN   | 9.0
4    | TOAN  | 6.0

Câu 1 (Dễ): Liệt kê tên và lớp của tất cả học sinh, sắp xếp theo tên tăng dần.

Đáp án
sql
SELECT HoTen, MaLop
FROM HocSinh
ORDER BY HoTen ASC;

Câu 2 (Dễ): Tìm các học sinh có điểm môn Toán từ 8.0 trở lên.

Đáp án
sql
SELECT hs.HoTen, dt.Diem
FROM HocSinh hs
INNER JOIN DiemThi dt ON hs.MaHS = dt.MaHS
WHERE dt.MaMon = 'TOAN' AND dt.Diem >= 8.0;

Câu 3 (Trung bình): Tính điểm trung bình môn Toán của từng lớp.

Đáp án
sql
SELECT hs.MaLop, AVG(dt.Diem) AS DiemTBToan
FROM HocSinh hs
INNER JOIN DiemThi dt ON hs.MaHS = dt.MaHS
WHERE dt.MaMon = 'TOAN'
GROUP BY hs.MaLop;

Câu 4 (Trung bình): Liệt kê tất cả học sinh và điểm môn Toán của họ. Học sinh nào chưa có điểm vẫn phải hiển thị.

Đáp án
sql
SELECT hs.HoTen, dt.Diem
FROM HocSinh hs
LEFT JOIN DiemThi dt ON hs.MaHS = dt.MaHS AND dt.MaMon = 'TOAN';

Học sinh Hoàng Minh Đức (MaHS=5) chưa có điểm Toán → cột Diem hiện NULL.

Câu 5 (Khó): Tạo bảng MonHoc(MaMon, TenMon, SoTiet) với MaMon là khóa chính, TenMon không được rỗng, SoTiet kiểu số nguyên.

Đáp án
sql
CREATE TABLE MonHoc (
    MaMon  VARCHAR(10)  PRIMARY KEY,
    TenMon VARCHAR(100) NOT NULL,
    SoTiet INT
);

Câu 6 (Khó): Tìm các lớp có số học sinh tham gia thi môn Toán nhiều hơn 1 người, và hiển thị điểm trung bình Toán của lớp đó.

Đáp án
sql
SELECT hs.MaLop, COUNT(*) AS SoHSThi, AVG(dt.Diem) AS DiemTBToan
FROM HocSinh hs
INNER JOIN DiemThi dt ON hs.MaHS = dt.MaHS
WHERE dt.MaMon = 'TOAN'
GROUP BY hs.MaLop
HAVING COUNT(*) > 1;

🔹 6. LỖI THƯỜNG GẶP – CHƯƠNG 4 ​

❌ Lỗi 1: Nhầm CSDL với DBMS ​

Sai: "MySQL là cơ sở dữ liệu"Đúng: MySQL là DBMS (phần mềm quản lý). Cơ sở dữ liệu là kho dữ liệu thực sự nằm bên trong MySQL.

❌ Lỗi 2: Nghĩ Primary Key chỉ cần Unique, không cần Not Null ​

Sai: Primary Key cho phép NULL miễn là giá trị không trùng Đúng: Primary Key bắt buộc phải vừa UNIQUE vừa NOT NULL — đây là hai điều kiện đồng thời.

❌ Lỗi 3: UPDATE/DELETE không có WHERE ​

Sai:

sql
UPDATE DiemThi SET Diem = 0;    -- Cập nhật toàn bộ bảng!
DELETE FROM HocSinh;             -- Xóa toàn bộ bảng!

Đúng: Luôn luôn thêm WHERE vào UPDATE và DELETE:

sql
UPDATE DiemThi SET Diem = 0 WHERE MaHS = 3 AND MaMon = 'TOAN';
DELETE FROM HocSinh WHERE MaHS = 3;

❌ Lỗi 4: Dùng WHERE thay vì HAVING để lọc nhóm ​

Sai:

sql
SELECT MaLop, COUNT(*) AS SoHS
FROM HocSinh
WHERE COUNT(*) > 30           -- ❌ Không thể dùng hàm tổng hợp trong WHERE
GROUP BY MaLop;

Đúng: Lọc nhóm sau GROUP BY phải dùng HAVING:

sql
SELECT MaLop, COUNT(*) AS SoHS
FROM HocSinh
GROUP BY MaLop
HAVING COUNT(*) > 30;         -- ✅

❌ Lỗi 5: Nhầm INNER JOIN với LEFT JOIN ​

  • INNER JOIN chỉ trả về hàng có khớp ở cả hai bảng → hàng không khớp bị mất
  • LEFT JOIN trả về tất cả hàng bảng trái dù không có khớp bên phải (cột bên phải = NULL)

❌ Lỗi 6: Nghĩ SQL phân biệt chữ hoa/thường với từ khóa ​

SQL không phân biệt chữ hoa/thường với từ khóa (SELECT, FROM, WHERE...). Nhưng phân biệt với giá trị chuỗi: WHERE TenMon = 'TOAN' khác WHERE TenMon = 'toan' (tùy DBMS).

❌ Lỗi 7: Nhầm DROP TABLE và TRUNCATE TABLE ​

  • DROP TABLE xóa cả bảng + dữ liệu + cấu trúc → không thể INSERT thêm vì bảng không còn
  • TRUNCATE TABLE chỉ xóa dữ liệu, giữ nguyên cấu trúc → có thể INSERT tiếp

🔹 7. GHI NHỚ NHANH TOÀN CHƯƠNG 4 (ĐI THI) ​

⚡ 20 điểm ghi nhớ quan trọng nhất

  1. CSDL = kho dữ liệu; DBMS = phần mềm quản lý (MySQL, PostgreSQL...)
  2. Bảng = cấu trúc lưu dữ liệu dạng hàng + cột
  3. Primary Key = UNIQUE + NOT NULL (bắt buộc cả hai)
  4. Composite PK = 2+ cột kết hợp (dùng khi không có cột đơn đủ duy nhất)
  5. Foreign Key = tham chiếu đến PK bảng khác → đảm bảo toàn vẹn tham chiếu
  6. SELECT * FROM Bảng WHERE điều_kiện
  7. BETWEEN 7 AND 9 = bao gồm cả 7 và 9
  8. LIKE 'Nguyễn%' = bắt đầu bằng 'Nguyễn'; LIKE '%an%' = chứa 'an'
  9. INNER JOIN = chỉ hàng khớp cả hai bảng; LEFT JOIN = tất cả hàng bảng trái
  10. ORDER BY ... ASC = tăng dần (mặc định); ORDER BY ... DESC = giảm dần
  11. DDL = CREATE / ALTER / DROP (thay đổi cấu trúc)
  12. DML = INSERT / UPDATE / DELETE (thay đổi dữ liệu)
  13. CREATE TABLE = tạo bảng mới với cột, kiểu dữ liệu, ràng buộc
  14. ALTER TABLE ADD/MODIFY/DROP COLUMN = thêm/sửa/xóa cột
  15. DROP TABLE xóa cả cấu trúc; TRUNCATE TABLE chỉ xóa dữ liệu
  16. INSERT INTO Bảng (cot1, cot2) VALUES (val1, val2)
  17. UPDATE và DELETE luôn cần WHERE để tránh ảnh hưởng toàn bảng
  18. Hàm tổng hợp: COUNT, SUM, AVG, MAX, MIN
  19. GROUP BY = nhóm hàng; HAVING = lọc nhóm (sau GROUP BY)
  20. WHERE lọc hàng riêng lẻ (trước GROUP BY); HAVING lọc nhóm (sau GROUP BY)
